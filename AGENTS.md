# AGENTS.md — правила разработки gloview

Прочитай перед изменениями. Структура: правила → архитектура → как работать →
чеклист. Рассказы о том, как что-то ломалось, живут в git history, не здесь.

Справочные данные — в `docs/REFERENCE.md`: карта исходников, блюр-пайплайн,
формат трейса, реестр анимаций, приоритет настроек.

---

## 0. Правило, важнее остальных

**Сначала посмотри лог, потом строй версию.**

Три правки подряд мимо одного бага — все три из рассуждения, все три мимо.
Закрыл баг четвёртая, после того как записал в лог входы решения.

Отсутствие записи в логе — не доказательство отсутствия события. Анимация, которая
применена, но не записана, неотличима от неприменённой. Это и есть разница между
«посмотрел» и «подумал».

Правило №0, конкретно:

| Ситуация | Что делать |
|---|---|
| «Выглядит неправильно» | Включить `debug_trace`, воспроизвести, прочитать `LIFE\|` `DRAG\|` `SCROLL\|` `SWAP\|` `ANIM\|` |
| Гипотеза о причине | Запись, которая подтвердит или опровергнет гипотезу — до правки кода |
| Правка «на всякий случай» | Запрещена. `git revert` дешевле, чем час в чужом коде |

## 1. Безопасность сессии — здесь ошибка стоит всего

Краш, use-after-free или RASSERT внутри плагина **роняет всю сессию пользователя**.

1. **Рискованные правки** (хуки, порядок проходов, teardown, private GL) — только
   в nested Hyprland.
2. **Хуки ставятся по demangled-signature substring**: `shouldRenderWindow`,
   `damageSurface`, `CSeatManager::setPointerFocus/setKeyboardFocus`.
   Несовпадение → `findFunctionsByName` пуст → `initialize()` вернул false →
   `plugin.load` это съедает → выглядит как «конфиг не подхватился».
   После обновления Hyprland: `ctest -R hook_signatures`.
3. **Hot-reload только через цель `reload`.** Она выгружает обе копии (build +
   hyprpm-кэш). Ручной `plugin load` рядом с hyprpm-копией даёт два инстанса, и
   второй молча остаётся без хука.
4. **`-fno-gnu-unique` не удалять из CMakeLists.** Иначе static-init guard'ы
   становятся STB_GNU_UNIQUE, glibc помечает `.so` NODELETE, `dlclose` не выгружает,
   и reload гоняет старый код.
5. **Перед `git checkout`** проверь файлы вне git: tracked на одной ветке +
   gitignored на другой = checkout их удалит без предупреждения.

## 2. Правила кода

| # | Правило | Почему |
|---|---|---|
| 2.1 | Immediate-mode GL — **только** через хелперы `gl_util.hpp`: `safeRenderRect`, `drawable()`, `dropShadow`, `strokeRing`/`strokeRingPx` | `renderRect`/`renderBorder`/`renderRoundedShadow` содержат `RASSERT(w>0 && h>0)` (`OpenGL.cpp:1071/2163/2341`). `pxb()` округляет — бокс меньше полупикселя становится нулём. Проверяет `scan_draw_sites` |
| 2.2 | Весь chrome — в monitor-local **логических** пикселях; перед GL — через `pxb()/pxr()`. `.round()` обязателен | pixman-регион `renderBorder` trunc'ает дробные боксы → дырки в тонких рамках |
| 2.3 | Всё, что рисует в приватный FBO: `RPT_EXPORT` + `fbSize=(W,H)` с сохранением и восстановлением окружения | иначе портится последующий рендер |
| 2.4 | Конфиг — **только** через `cfg*`-хелперы (V2 `value()`) | `HyprlandAPI::getConfigValue()` игнорирует Lua-конфиг |
| 2.5 | `const double x = cfg::…` в namespace scope — **нельзя** | инициализатор до `PLUGIN_INIT`, конфиг ещё не прочитан |
| 2.6 | Заголовки Lua (`<lua.h>`, `<lauxlib.h>`) — всегда внутри `extern "C"` | без него `dlopen` падает с `undefined symbol: _Z14luaL_checktype` **до** `PLUGIN_INIT`. Файлы: `src/anim.cpp`, `src/clock/curves.cpp` |
| 2.7 | Порядок `paint()` не менять без причины (`render/painter.cpp`) | см. таблицу ниже |
| 2.8 | Файлы, которые ctest компилирует без `hyprland/`, не получают его include **никогда** | один include превращает тест на 0.4 с в ошибку линковки. Проверяет `scan_hypr_types` |
| 2.9 | Карта по окнам держит **владельца**: значение несёт `PHLWINDOWREF` и роняет запись при `expired()` | проверять тип ключа бессмысленно: все три map'а в `pixel/cache.hpp` ключуются сырым `CWindow*` и все три правы |
| 2.10 | Каждый `m_clocks.*.begin()` обязан стоять рядом с `trace::animStart`, либо быть в списке исключений **с причиной** | анимация, применённая но не записанная, неотличима от неприменённой. Проверяет `scan_anim_coverage` |
| 2.11 | `hl.config{…}` в пользовательском конфиге — **только под `pcall`**. `hl.plugin.load` тоже под `pcall` | без pcall ошибка одного ключа обрушивает загрузку конфига — Hyprland выходит молча, без падения и без отчёта. `plugin.load` глотает ошибку загрузки `.so`, и это выглядит как «конфиг не подхватился» |
| 2.12 | **`currentFB` нельзя использовать как источник блюра/полос** | фуллскрин-окно на активном воркспейсе идёт через «solitary client» fast path в обход `shouldRenderWindow`. Источники только `backdropSource()` / `renderBackdropSource()` |
| 2.13 | **Не деактивировать mid-frame** — финальный кадр овервью должен отрисоваться | иначе один прозрачный кадр поверх десктопа. Механику держит `Lifecycle::requestDeactivate()`, но порядок вызовов остаётся на `lifecycle.cpp` |
| 2.14 | **Владение вводом ≠ скрытие окон** | `shouldRenderWindow` прячет окна только от рендерера; фокус им раздаёт `CSeatManager`, и через `Event::bus()` это не отменяется. Пока овервью владеет экраном (**включая паркованные кадры** — `openedOrParked()`, не `active()`), хуки `setPointerFocus`/`setKeyboardFocus` не дают фокусу уйти в окна. Хук на `send*` бесполезен — seat продолжает считать окно сфокусированным |

## 3. Архитектура

### 3.1 Что чем владеет

```
Overview                     единственный владелец всего состояния; НЕ юнит-тестируем
├── model::Scene             плитки, выбор, интенты          (инвариант → тест)
├── model::Effects           ghosts, pulses, swapfx           (инвариант → тест)
├── model::Strip             карточки стрипа                 (инвариант → тест)
├── model::Recency           порядок фокуса                  (инвариант → тест)
├── model::DragT<WinRef>     ФСМ перетаскивания             (инвариант → тест)
├── model::Lifecycle         ФСМ владения экраном           (инвариант → тест)
├── model::ScrollState       позиции скролла стрипа          (инвариант → тест)
├── view::State              режимы: run / desktop / flip    (чистые данные)
├── clock::Clocks            tween'ы и прогрессы             (чистые данные)
├── render::BlurCache        кэш блюра                       (GL)
├── pixel::PixelCache        подписи, снапшоты               (GL)
└── CCursorModule            курсор                          (GL)
```

Подсистемы с логикой вынесены в `src/model/` и шаблонизированы на тип-ручку окна,
чтобы их можно было тестировать без композитора. Шаблон — не косметика: без него
`drag.hpp` и `lifecycle.hpp` не поднялись бы в ctest вообще.

**Что осталось в `Overview`** и потому не покрыто юнит-тестами: координация между
подсистемами — `swapWindows`, `toggleAllWorkspaces`, `switchToWorkspace`,
`syncTiles`. Эти функции нельзя вызвать без композитора. Их покрывает **трейс**, а
не тест. Планировать покрытие для них юнитами — пустая трата.

### 3.2 Подсистема как тип — процедура

1. **Сначала измерить границу записи.** Кто пишет. Пока писал один файл, изоляция
   уже существовала и её надо было только оформить (drag). Границы, замкнутые в
   одном `.cpp`, выносить незачем (backdrop — отменено).
2. **Поля приватные, наружу переходы и запросы.** Инвариант становится структурным,
   когда единственный путь в состояние ставит всё, что этому состоянию принадлежит.
3. **Шаблон на тип-ручку**, если внутри есть Hyprland-тип. Это и открывает тест.
4. **Один файл пишет — из него же и трейс.** Запись, которой не было, невозможна.
5. **`describe()` принадлежит типу**, не эмиттеру. Поле, добавленное в ФСМ, не может
   отсутствовать в записи.

### 3.3 Три разных вопроса о состоянии

`Overview::active()`, `openedOrParked()`, `opening()` — **не** взаимозаменяемы:

| Вопрос | Метод | Ответ про парковку |
|---|---|---|
| Овервью видно? | `active()` | **нет** — парковка ничего не рисует |
| Овервью владеет экраном? | `openedOrParked()` | **да** — окна должны потерять фокус на первом паркованном кадре |
| Идёт входная анимация? | `opening()` | не обязана |

`m_opening` **не** на той же оси, что владение: `replayReflow` и `switchToWorkspace`
ставят его на уже открытом овервью, чтобы переиграть вход на изменившихся плитках.
Поэтому в коде девять мест писали `active() && opening()` — это один вопрос, заданный
девятью способами. Спроси одним именем: `m_life.openingNow()`.

### 3.4 Порядок `paint()`

```
backdrop → tiles/carousel → ghosts → pulses → strip → strip windows
        → strip buttons → pulses → swapfx → drag → aboveLayers → cursor
```

Правило: **сидящее ПОВЕРХ контента рисуется ПОСЛЕ него.** Кнопки — после своих
поверхностей, иначе opaque-контент окон затирает их.

Два осознанных исключения: счётчик карусели рисуется **ДО** карточек;
`pushOut()` двигает хром из paint.

## 4. Семантика, которую легко сломать

- **`close()`: resume закрытия** — `m_timeline.seek(1.0 - m_progress)`; при закрытии
  `m_progress = 1 - timeline.raw()`. Инверсия направления. **Менять вместе.**
- **Кэш блюра — чистый блюр.** Без dim и без анимации: dim рисуется отдельным
  rect'ом поверх блита, fade — только альфа блита. `blur_strength` — **только**
  радиус фильтра. Ключ кэша = srcId + passes/size/resolution/strength, проверяется
  **каждый кадр вне dirty-guard** — единственный способ поймать смену источника.
- **Бэкдроп-композит НЕ протухает.** Живёт, пока источник реально не сменится.
  Неудачная попытка уходит в scratch-Framebuffer и не может затереть удачную.
  (TTL в 3 с был причиной чёрного первого кадра.)
- **Границы перехода — политика, утверждена пользователем.** Реальные окна
  переключаются жёстко: скрыты с первого кадра `open`, восстановлены только после
  полного окончания `close`. Фейдов окна нет — во время глайда окно меняет размер и
  позицию, тающий оригинал под плывущим превью читается как задвоение. Бесшовность
  дают превью, **попиксельно идентичные** реальным окнам в natural-боксах на обоих
  концах. Фейд — только у блюра.
- **Tween:** длительности читаются на месте **каждый кадр** (живой отклик на смену
  конфига). Tween владеет только стартовой точкой.
- **`close()` НЕ сбрасывает режим all-workspaces.** `setAllOverride(-1)` живёт
  только в `deactivate()`. Отсюда: сетка в all-workspaces имеет обнулённый `target`,
  `currentBox()` держит карточку на `natural`, `tileAtRest` ложно, слот-обмен
  пропускается. Любой инструмент, дёргающий `allws`, обязан восстанавливать режим.

## 5. Исходники композитора — читать тело, а не объявление

Заголовки в `/usr/include/hyprland` **объявляют** функции, но не содержат тел.
`RASSERT` живёт в `.cpp`. Вопрос «что здесь проверяет Hyprland» без исходников не
имеет ответа, а ответ на него стоил сессии.

```bash
./tools/sync_upstream.sh          # клонировать + взять ревизии живой сессии
./tools/sync_upstream.sh --check  # сверить, что дерево соответствует сессии
```

```
~/dev/clone/Hyprland      ревизия из hyprctl version (полный SHA1)
~/dev/clone/aquamarine    ревизия из свежего crash-отчёта
```

HEAD — другое дерево. «В исходниках написано» про неработающий код хуже, чем
отсутствие исходников.

## 6. Диагностика падений

```bash
ls -t ~/.cache/hyprland/hyprlandCrashReport*.txt | head -1   # точный стек, ПЕРВЫМ
tail -100 /run/user/$(id -u)/hypr/$(ls -t /run/user/$(id -u)/hypr | head -1)/hyprland.log
```

**Имя функции в crash-отчёте может быть выдуманным.** После hot-reload символизатор
резолвит адрес по symtab старой сборки. Сверять `nm -DC build/gloview.so`.

**Не** `hyprctl --verify-config` — роняет композитор и подсовывает чужие core-дампы.
**Не** `rm -rf /run/user/$(id -u)/hypr/*` — уносит логи живых сессий.

**У гипотезы есть красный цикл.** Версия без него — не находка. Сегодня это стоило
трёх коммитов и часа: три правки подряд выдавались за чинит по рассуждению, пока
не появилась запись в лог.

## 7. Сборка и проверка

```bash
cmake --build build -j$(nproc)          # цель build/gloview.so; зелёная сборка = минимум
cmake --build build --target reload     # пересобрать + горячая перезагрузка
cd build && ctest --output-on-failure   # 20 проверок
```

**Судить по дате `build/gloview.so`, не по выводу сборки.** `cmake --build` печатает
`[100%] Built target` даже когда make под ним падает — код 0, ошибки в stderr.
Инкрементальная сборка прячет warning'и в неизменённых TU.

### Тесты: 20, две группы

| Префикс | Что это |
|---|---|
| `scan_*` | **статика.** Читают исходники и сверяют с правилом. Не исполняют логику |
| остальные | исполняют: чистые типы юнитом, `hook_signatures`/`load_seam` — против живого бинарника |

Имена не врут: `scan_config_keys`, `scan_draw_sites`, `scan_hypr_types`,
`scan_anim_coverage` — гrep по исходникам, остальное исполняет код.

**Харнесс может пройти, ничего не проверив.** `strip_scroll_clamps` однажды вернул PASS
на четырёх записях `max=0` — инвариант `0 ≤ current ≤ max` истинно тривиально при
нулевом диапазоне. Теперь требует хотя бы одну запись с `max > 0`, иначе SKIP.

**SKIP — не PASS.** Пустой лог не доказательство.

## 8. Трейс и автоматизация

```bash
hyprctl eval 'hl.plugin.gloview.cmd("open")'      # под Lua-конфигом это hl.plugin.gloview.cmd
python3 tools/runtime_check.py [--list] [lifecycle|scroll|drag]
python3 tools/anim_matrix.py [--quick] [--scenarios]
```

`hyprctl dispatch`/`eval` под Lua-конфигом до диспатчеров плагина не доходят.
Каждая команда подтверждает себя в логе: `CMD|ok` / `CMD|err`. `hyprctl eval`
не печатает возвращаемое значение — **лог единственный канал успеха**.

Трейсы: `LIFE|` `DRAG|` `SCROLL|` `SWAP|` `ANIM|` — грамматика одна,
`key=value` через `|`, без пробелов. Один парсер читает все семейства.
Формат и все поля: `docs/REFERENCE.md` §3.

`debug_trace` — **сбрасывается при каждом reload** (новый инстанс плагина).
Включай заново после `reload`, иначе кейсы дадут SKIP, а не результат.

Приоритет настроек снизу вверх: строка `kRows` → `set` (команда) →
rule из `gloview.animation` → config-значение. **Rule бьёт config.**

## 9. Как работать

- **Один логический шаг = один коммит.** Коммит только после зелёной сборки.
  Сообщение `type(scope): summary` на английском, тело объясняет why.
- **Проверяй, что комментарий не содержит маркер твоего же теста.** Шесть раз за
  одну сессию то, что я писал, ломало мою же проверку: комментарий с `kNames`,
  утверждение про перелёт кривой, строка-маркер в `anim_styles`, литерал
  `m_clocks.rebuild.begin()` в пояснении к `scan_anim_coverage`.
- **Тест, который ничего не наблюдал, не считается прошедшим.** Считай, что
  *наблюдал* — не что *записей было*.
- **Инструмент, меняющий состояние, обязан восстанавливать его.** `runtime_check`
  дёргал `allws` и закрывал овервью; `close()` режим не сбрасывает — и следующий
  ручной прогон выполнялся в чужом режиме. Выглядело как регрессия в коде свопа.
- **Комментарии в коде** — английские, докунят «почему» и **проверенные** факты о
  внутренностях Hyprland (файл:строка источника). Непроверенное утверждение о
  коде хуже его отсутствия: инвариант `m_backdropDrawn ⇒ srcTex == lastObservedTex`
  был ложен для анимированного источника, и его записали бы как защиту.
- **Дедупликация прежде копипасты:** повторённый 3+ раз паттерн → хелпер
  (`captureCurrentBoxes`, `releaseNewWorkspaces`, `tileRect`, `landAfterSwap`).
  Хит-тесты — через `LRect::contains`.
- Стиль: 2 пробела; `layout.*` исторически 4 — не переформатировать целиком.
- Без эмодзи. README обновлять, если меняется поведение или добавляются конфиги.
- **Файлы заметок и памяти агента — вне git.** `GloView*.md` в `.gitignore`.

## 10. Ручные тест-кейсы

`docs/manual-test-cases.md` — 44 кейса, подмножество по номерам.

`·часто·` — **12 кейсов на любое изменение, 4–6 минут.** Остальные — перед
релизом или после большой переработки. Признак, а не smoke/sanity/regression:
один набор без дублирования, и **набор без быстрого среза не гоняют вообще**.

## 11. Чеклист перед коммитом

- [ ] сборка зелёная — **error И warning** (вывод врёт, судить по дате `.so`)
- [ ] `ctest` зелёный; новый тест **краснеет** при откате своей правки
- [ ] тест, у которого нечего наблюдать, даёт SKIP, а не PASS
- [ ] нет обращений к удалённым членам/API (grep по имени)
- [ ] новая анимация: рядом с её `m_clocks.*.begin()` стоит `trace::animStart`
- [ ] новый конфиг: `kInts`/`kFloats`/`kStrs`/`kColors` в `config.cpp` **и** строка в README
- [ ] поведение по умолчанию не изменилось (если это не задумано)
- [ ] этот файл обновлён, если изменилась семантика
